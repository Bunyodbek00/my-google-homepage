# Google Home Page Clone

A responsive recreation of the Google homepage, built with plain HTML and CSS as part of a web development course.

## Overview

This project recreates the core layout and interactions of Google's homepage, including:

- Header navigation with About/Store links and Gmail/Images/profile section
- Search bar with icon, input, and microphone/camera buttons
- Search action buttons ("Google Search" / "I'm Feeling Lucky")
- Footer with location, links, and responsive column layout

## Features

- **Responsive design** — layout adapts at a 640px breakpoint (nav text and footer columns rearrange for larger screens)
- **Flexbox layout** — nested flex containers throughout for alignment and spacing
- **Custom fonts** — Google Fonts (Inter, Poppins)
- **Icon library** — Font Awesome for search, microphone, camera, and nav icons
- **Interactive states** — hover effects on links, buttons, and the search bar; focus state on the input

## Tech Stack

- HTML5
- CSS3 (Flexbox, media queries, pseudo-classes)
- [Font Awesome](https://fontawesome.com/) (icons)
- [Google Fonts](https://fonts.google.com/) (Inter, Poppins)
